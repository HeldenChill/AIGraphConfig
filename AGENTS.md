# AIConfigGraph — Agent Context (Codex, Cursor, Gemini)

Local web tool for seeing an AI setup: token use per session, prompt and call, and later a graph of rules, memories, playbooks, skills and hooks across projects. Single user (the owner), runs on this PC, read-only in version one.

Not a Unity project. The Unity identity tokens in `project.config.json` are `n/a`.
